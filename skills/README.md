# Repository skills

These are small, repository-local skills for recurring agentic development tasks. They are guidance, not a substitute for reviewing infrastructure plans or authorizing production changes.

- [`infrastructure-change`](./infrastructure-change/SKILL.md) — Nix, OpenTofu, Hetzner, networking, storage, and service deployment changes.
- [`backup-restore`](./backup-restore/SKILL.md) — backup policy, local staging and S3-compatible storage, restore drills, and recovery testing.
- [`maintenance`](./maintenance/SKILL.md) — upgrades, routine operations, incident response, and runbook changes.
- [`herdr-control`](./herdr-control/SKILL.md) — safe, explicit Herdr pane, tab, workspace, and agent control.
- [`parallel-codex`](./parallel-codex/SKILL.md) — isolate, brief, monitor, and verify concurrent Codex work.
- [`meta-self-improvement`](./meta-self-improvement/SKILL.md) — capture durable lessons and improve future agent runs.

Keep skills focused. Add a supporting reference or script only when it captures maintained project-specific knowledge that would otherwise be repeatedly rediscovered.
